راهنمای نصب پنل روی Railway (به‌جای هاست اشتراکی)
============================================================

این پوشه (railway-deploy) شامل:
  Dockerfile        -> ایمیج PHP+Apache با افزونه‌های لازم
  entrypoint.sh      -> فعال‌سازی Volume دائمی برای config.php / storage / uploads

چرا Dockerfile لازم است؟
Railway به‌صورت خودکار پروژه‌های PHP خالص (بدون composer.json) را
تشخیص نمی‌دهد، پس با Dockerfile مستقیم و دقیق ایمیج را می‌سازیم.

------------------------------------------------------------
مرحله ۱: ساخت پروژه در Railway
------------------------------------------------------------
1) وارد railway.app شوید -> New Project -> Deploy from GitHub repo
2) ریپازیتوری‌ای که شامل کل پوشه 01-vpn-panel-php است را انتخاب کنید
   (railway-deploy باید زیرپوشه‌ی همین ریپو باشد، نه جدا)
3) در تنظیمات سرویس:
   Root Directory       = مسیر پوشه پنل (مثلاً همان ریشه ریپو)
   Dockerfile Path       = railway-deploy/Dockerfile

------------------------------------------------------------
مرحله ۲: افزودن دیتابیس MySQL
------------------------------------------------------------
داخل همان پروژه Railway:
+ New -> Database -> Add MySQL

Railway به‌صورت خودکار متغیرهایی مثل MYSQLHOST، MYSQLPORT،
MYSQLDATABASE، MYSQLUSER، MYSQLPASSWORD می‌سازد.
هنگام اجرای مرحله /install/ همین مقادیر را در فرم نصب وارد کنید
(DB Host = MYSQLHOST، DB Name = MYSQLDATABASE و ...).
اگر MySQL روی همان پروژه باشد، سرویس پنل با نام Private Network
به آن دسترسی دارد (مثلاً mysql.railway.internal).

------------------------------------------------------------
مرحله ۳: افزودن Volume دائمی (خیلی مهم)
------------------------------------------------------------
روی سرویس پنل -> تب Volumes -> New Volume
Mount Path را دقیقاً بگذارید:

    /data

بدون این Volume، هر بار که کد را دوباره Deploy کنید config.php و
لینک‌های ذخیره‌شده پاک می‌شوند و باید دوباره نصب کنید.

------------------------------------------------------------
مرحله ۴: متغیرهای محیطی سرویس
------------------------------------------------------------
در تب Variables این‌ها را اضافه کنید (اختیاری ولی توصیه می‌شود):

PHP_TZ=UTC

Railway خودش PORT را ست می‌کند؛ entrypoint.sh آن را می‌خواند و
Apache را روی همان پورت بالا می‌آورد، کاری از شما لازم نیست.

------------------------------------------------------------
مرحله ۵: Deploy و اجرای نصب‌گر
------------------------------------------------------------
1) Deploy را بزنید و صبر کنید Build/Deploy سبز شود
2) از تب Settings روی سرویس، یک Public Domain بسازید
   (یا دامنه شخصی خودتان را Custom Domain کنید؛ Railway گواهی
   SSL را خودش صادر می‌کند)
3) به آدرس زیر بروید:
   https://YOUR-RAILWAY-DOMAIN/install/
4) فرم نصب را با اطلاعات MySQL که از مرحله ۲ گرفتید پر کنید.
   Base URL = همان دامنه Railway (بدون / آخر)

بعد از نصب، App API Key / Cron Token / Admin Gate را دقیقاً مثل
حالت هاست معمولی ذخیره کنید و در GitHub Secrets پروژه اندروید
(VPN_API_BASE_URL و VPN_APP_API_KEY) استفاده کنید.

------------------------------------------------------------
مرحله ۶: Cron برای Refresh خودکار
------------------------------------------------------------
Railway کرون داخلی سنتی ندارد. دو گزینه:

الف) ساده‌ترین: Railway -> New -> Cron Job (اگر در پلن شما فعال است)
   دستور: curl -fsS "https://YOUR-DOMAIN/cron/refresh.php?token=YOUR_CRON_TOKEN"
   زمان‌بندی: مثلاً هر 10 دقیقه (*/10 * * * *)

ب) جایگزین: از یک سرویس بیرونی رایگان مثل cron-job.org همان URL
   بالا را هر 10 دقیقه صدا بزنید.

------------------------------------------------------------
نکات
------------------------------------------------------------
- بعد از هر Deploy جدید کد، چون config.php و storage از طریق
  Volume در /data نگه داشته می‌شوند، نیازی به نصب دوباره نیست.
- اگر Volume را عوض/پاک کنید، باید install/ را دوباره اجرا کنید.
- برای دیدن لاگ‌ها: تب Deployments -> View Logs.
