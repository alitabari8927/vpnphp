# VPN Panel 1.0.0

پنل سبک PHP/MySQL برای مدیریت Subscriptionهای VPN و تبلیغات اپ اندروید.

## نیازمندی‌ها
- PHP 8.1+
- MySQL 5.7+ / MariaDB 10.4+
- افزونه‌های PHP: PDO MySQL, cURL, JSON, OpenSSL, Fileinfo (نصب‌گر قبل از نصب آن‌ها را بررسی می‌کند)
- HTTPS توصیه می‌شود.

## نصب
1. کل پوشه را روی هاست آپلود کنید.
2. دامنه/ساب‌دامنه را به پوشه پروژه متصل کنید.
3. مطمئن شوید پوشه‌های `storage/` و `uploads/ads/` قابل نوشتن هستند.
4. مسیر `/install/` را باز کنید و مشخصات دیتابیس و مدیر را وارد کنید.
5. نصب‌گر یک `Admin Gate` می‌سازد. فقط URL مخفی‌ای که هنگام نصب نشان داده می‌شود صفحه ورود را باز می‌کند؛ مراجعه مستقیم به `/admin/` بدون Gate در نشست جدید به 404 می‌رسد.
6. در Cron هاست، هر 5 یا 10 دقیقه دستور زیر را تنظیم کنید:
   `php /home/USER/public_html/cron/refresh.php`

> فایل `config.php` حاوی اطلاعات حساس است و توسط `.htaccess` مسدود می‌شود. در صورت امکان permission آن را 640 قرار دهید.

## API اپ
- `GET /api/v1/manifest.php`
- هدر: `X-App-Key: <APP_API_KEY>`
- هدرهای اختیاری برای مدیریت دستگاه: `X-Device-Id`, `X-Device-Model`, `X-Device-Manufacturer`, `X-Android-Version`, `X-App-Version` (اپ اندروید همراه پروژه این‌ها را خودکار ارسال می‌کند)
- خروجی شامل `servers` و `ads` (شیء با دو آرایه `pre_connect` و `post_connect`) است.
- Subscription URL اصلی هیچ‌وقت در خروجی API نمایش داده نمی‌شود.
- اگر دستگاهی از پنل مسدود شده باشد، پاسخ 403 با `error: device_blocked` برمی‌گردد.
- `POST /api/v1/ad-event.php` با بدنه `{"ad_id":1,"event":"impression"|"click"}` و هدر `X-App-Key` برای ثبت بازدید/کلیک تبلیغ.

## مدیریت تبلیغات (Admin > تبلیغات)
- دو جایگاه نمایش: تمام‌صفحه قبل از اتصال، و بنر کوچک بعد از اتصال موفق.
- چند تبلیغ هم‌زمان در هر جایگاه قابل تعریف است؛ اپ با وزن‌دهی بر اساس «اولویت» بین آن‌ها چرخش می‌کند (نه فقط یک تبلیغ ثابت).
- زمان‌بندی نمایش با تاریخ شروع/پایان اختیاری (برای کمپین‌های موقت)، همراه با نشان‌دادن وضعیت «زمان‌بندی‌شده / فعال / منقضی».
- آمار بازدید، کلیک و CTR هر تبلیغ + جمع کل روی کارت‌های بالای صفحه.
- روشن/خاموش کردن سریع هر تبلیغ بدون نیاز به ویرایش کامل.

## مدیریت دستگاه‌ها (Admin > دستگاه‌ها)
- لیست همه دستگاه‌هایی که تاکنون با اپ به سرور وصل شده‌اند: مدل گوشی، سازنده، نسخه اندروید، نسخه اپ، IP، اولین و آخرین اتصال.
- وضعیت آنلاین/آفلاین (بر اساس آخرین چک‌این کمتر از ۳ دقیقه پیش).
- جستجو بر اساس مدل، سازنده، IP یا شناسه دستگاه، و فیلتر آنلاین/مسدود.
- مسدود کردن یا آزاد کردن هر دستگاه (دستگاه مسدود دیگر سروری از API دریافت نمی‌کند).
- حذف رکورد دستگاه و خروجی گرفتن CSV از کل لیست.
- آمار خلاصه (کل دستگاه‌ها، آنلاین الان، مسدود شده) روی داشبورد اصلی هم نمایش داده می‌شود.

## آپدیت
ساختار پروژه طوری است که `config.php`، `storage/` و `uploads/` خارج از چرخه جایگزینی کد هستند. در نسخه‌های بعدی فایل‌های برنامه را جایگزین کنید و سپس از Admin > Update Center مهاجرت دیتابیس را اجرا کنید.

## امنیت و محدودیت مهم
- صفحه ریشه عمداً 404 برمی‌گرداند و پنل فقط از مسیر ادمین قابل دسترسی است.
- robots.txt ایندکس را منع می‌کند، اما این کار تضمین نمی‌کند که دامنه توسط سرویس‌دهنده یا نهاد ثالث شناسایی نشود.
- نودهای اتصال باید نهایتاً به دستگاه برسند تا اپ بتواند وصل شود؛ بنابراین مخفی‌کردن کامل اطلاعات اتصال از کاربر حرفه‌ای/مهندسی معکوس ممکن نیست.
